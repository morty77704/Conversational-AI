# 转正申请材料清单（学习项目示例）

> 本清单是 ABC Technology 学习项目演示数据，不代表真实公司的转正要求。

## 必需材料

| 材料 | 提交或提供人 | 是否必需 | 提交时间 | 主要内容 |
| --- | --- | --- | --- | --- |
| 转正申请表 | 员工 | 是 | 试用期届满前十个工作日 | 基本信息、岗位、入职日期、申请意见 |
| 试用期工作总结 | 员工 | 是 | 与申请表同时 | 主要工作、成果、问题、后续计划 |
| 试用期目标完成情况自评 | 员工 | 是 | 与申请表同时 | 按入职时确认的目标逐项说明结果和证据 |
| 直属主管评价表 | 直属主管 | 是 | 收到申请后三个工作日内 | 业绩、能力、岗位匹配、职业行为和转正建议 |
| 部门负责人复核意见 | 部门负责人 | 是 | 主管评价后两个工作日内 | 编制、目标结果、主管建议和部门意见 |
| 考勤与纪律记录 | 人力资源部 | 是 | HR复核时 | 迟到、缺勤、请假及已确认的纪律事项 |
| 必修培训完成记录 | 人力资源部或培训负责人 | 是 | HR复核时 | 入职培训、信息安全和岗位必修课程 |

## 条件性材料

下列材料仅在岗位或实际情况适用时提交：岗位资格证书或上岗证明、培训考试成绩、项目验收或客户反馈、提前转正说明、材料逾期补交说明、审批例外说明。

未要求的个人敏感信息不得作为转正材料收集。医疗、家庭状况等与岗位录用条件无关的信息，不得作为转正评价依据。

## 快速回答

当员工询问“试用期转正需要准备哪些材料”时，应优先回答员工本人需要准备的三项必需材料：转正申请表、试用期工作总结、试用期目标完成情况自评；再说明岗位有资质或考试要求时需要补充相应证明。主管评价、考勤纪律和培训记录分别由主管、部门和人力资源部提供，不应全部要求员工自行准备。
